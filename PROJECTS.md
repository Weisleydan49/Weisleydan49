# Projects

Full write-ups for the projects featured on my profile. The README links here so the main page stays scannable.

## 🚌 SAFARI-SALAMA

A matatu route optimization and safety system for commuters. Maps common routes across Nairobi and surfaces safety data so riders can choose better trips before they board.

- **Stack:** Python backend · Flutter frontend · PostgreSQL database
- **Repo:** [github.com/almondweisley/SAFARI-SALAMA](https://github.com/almondweisley/SAFARI-SALAMA)

## 📱 SignalGrid

A cross-platform mobile app with a Node API behind it, built for autonomous community incident reporting. Designed so reports flow in from the field with minimal friction and land somewhere useful.

- **Stack:** Flutter · Dart · Node.js + MongoDB
- **Repo:** [github.com/almondweisley/SignalGrid](https://github.com/almondweisley/SignalGrid)

## 🧠 Project Castro

- **Stack:** HTML · CSS
- **Repo:** [github.com/almondweisley/Project_Castro](https://github.com/almondweisley/Project_Castro)
